# Go Kod Bot

## Цель проекта
Telegram-бот, который помогает находить небанальные маршруты по Петербургу. Пользователь выбирает тему, а бот собирает интерактивный маршрут из уникальных локаций с описанием и ссылкой на сайт spbkod.ru для бронирования.

## Основные возможности

### Выбор темы маршрута
- **Цель:** Пользователь хочет выбрать интересующую тему для прогулки
- **Описание:** При старте бот приветствует пользователя вопросом «Куда хотите отправиться?» и показывает кнопки с темами: «Архитектура», «Мистика», «Особняки», «Литература», «Современный Петербург». Пользователь нажимает на тему и получает маршрут.
- **Критерии приёмки:**
  - При старте бот приветствует пользователя с вопросом «Куда хотите отправиться?»
  - Список тем отображается всегда, когда пользователь может сделать выбор
  - Доступны темы: Архитектура, Мистика, Особняки, Литература, Современный Петербург
  - Каждая тема имеет понятное название и короткое описание

### Приветствие от имени гида
- **Цель:** Пользователь чувствует, что его встречает живой гид, а не программа
- **Описание:** При команде /start бот приветствует пользователя дружелюбным сообщением от имени Михаила из «Кода Петербурга», автоматически подставляя имя пользователя из Telegram. Текст приветствия: «Привет! Это Михаил из «Кода Петербурга». Рад, что ты заглянул! Я не просто бот, а твой гид по небанальным маршрутам, которые я сам собрал, потому что влюблён в этот город. Готов исследовать?» с дружелюбным эмодзи в конце.
- **Критерии приёмки:**
  - При команде /start отображается дружелюбное приветствие от имени Михаила из «Кода Петербурга»
  - В приветствие автоматически подставляется имя пользователя из Telegram
  - Текст приветствия соответствует заданному и заканчивается дружелюбным эмодзи

### Генерация маршрута по теме
- **Цель:** Пользователь хочет получить готовый маршрут по выбранной теме
- **Описание:** После выбора темы бот собирает маршрут из 3–5 ключевых точек, связанных с темой. Каждая точка содержит название, короткое описание, адрес и ссылку на фото. В конце маршрута — фраза «Хотите увидеть это с гидом? Забронируйте экскурсию на сайте spbkod.ru» с ссылкой.
- **Критерии приёмки:**
  - Маршрут содержит 3–5 точек с названием, описанием, адресом и фото
  - После маршрута отображается фраза с призывом забронировать на spbkod.ru
  - Маршрут можно получить заново или вернуться к выбору темы

### Детали точки маршрута
- **Цель:** Пользователь хочет узнать подробнее о конкретной локации
- **Описание:** Нажав на кнопку под точкой маршрута, пользователь получает расширенное описание: историю места, интересный факт, рекомендацию когда лучше прийти и ссылку на фото.
- **Критерии приёмки:**
  - У каждой точки маршрута есть кнопка «Подробнее»
  - Расширенное описание содержит историю или интересный факт и фото
  - Из деталей можно вернуться к маршруту

### Сохранение и шеринг маршрута
- **Цель:** Пользователь хочет сохранить маршрут или поделиться им
- **Описание:** Бот предлагает кнопки «Поделиться» (копирование маршрута текстом) и «Сохранить» (короткая памятка с точками).
- **Критерии приёмки:**
  - Кнопка «Поделиться» копирует маршрут в удобном текстовом формате
  - Кнопка «Сохранить» показывает компактную версию маршрута

### Работа в Telegram
- **Цель:** Пользователь может пользоваться ботом прямо в Telegram
- **Описание:** Бот работает как настоящий Telegram-бот: подключается к Telegram через Bot API, обрабатывает команды (/start, /help, /about) и нажатия на кнопки, отправляет маршруты и детали точек прямо в чат Telegram. Размещается на сервере (Railway) и работает 24/7.
- **Критерии приёмки:**
  - Бот отвечает на команду /start дружелюбным приветствием от имени Михаила с подстановкой имени пользователя
  - Бот показывает кнопки с темами маршрутов
  - При выборе темы бот отправляет маршрут с точками, описаниями, адресами и фото
  - У каждой точки есть кнопка «Подробнее» с расширенным описанием
  - Бот работает на сервере (Railway) и доступен в Telegram

## Дополнительные заметки
- Стиль общения: дружелюбный гид, неформальный, как совет от друга
- Интерфейс: кнопки Telegram, минимум текста на экране выбора
- Все маршруты ведут на spbkod.ru для бронирования
- Первая версия — конструктор: бот собирает маршрут из базы точек по выбранной теме
- Приветствие: «Куда хотите отправиться?»
- Конкретные темы: Архитектура, Мистика, Особняки, Литература, Современный Петербург
- У точек маршрута есть ссылка на фото для визуальной привлекательности
- После маршрута — мягкий призыв забронировать экскурсию на spbkod.ru
- На главной странице над приветствием отображается логотип Go Kod Bot, оцентрованный по центру
- Приветствие /start — дружелюбное, от имени Михаила из «Кода Петербурга», с автоматической подстановкой имени пользователя из Telegram и дружелюбным эмодзи в конце
- Тексты кнопок (/help, /about и подобных) приведены к единому неформальному стилю, как у маршрутов
- В системе настроены корректные название, описание профиля и аватар (логотип проекта) для отображения в интерфейсе Telegram
- Под вопросом «Куда хотите отправиться?» отображается текст «Выберите тему прогулки по Петербургу ниже, и мы отправимся вместе» с аккуратной стрелочкой вниз по центру
- Токен бота хранится в переменной окружения (не в коде)

### Маршрут «Архитектура»: От императорского барокко до модерна на Петроградке
- **Цель:** Пользователь хочет пройти маршрут по архитектурным эпохам Петербурга
- **Описание:** Маршрут из 6 точек, охватывающий несколько эпох: елизаветинское барокко (Смольный собор), петровское барокко (Кикины палаты), классицизм (Таврический дворец), северный модерн (Доходный дом на Большом проспекте, 26), поздний модерн (Дом с совами) и неоклассицизм с египетским декором (Дом Нежинской). Общая протяжённость ~6 км, время прохождения 2.5–3 часа. Каждая точка содержит название, адрес, архитектурный стиль, год постройки, описание и логистику перехода к следующей точке.
- **Критерии приёмки:**
  - Маршрут «Архитектура» содержит 6 точек: Смольный собор, Кикины палаты, Таврический дворец, Доходный дом на Большом проспекте 26, Дом с совами, Дом Нежинской
