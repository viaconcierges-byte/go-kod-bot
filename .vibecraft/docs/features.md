# Go Kod Bot

## Цель проекта

Telegram-бот, который помогает находить небанальные маршруты по Петербургу. Пользователь выбирает тему, а бот собирает интерактивный маршрут из уникальных локаций с описанием и ссылкой на сайт spbkod.ru для бронирования.

## Основные возможности

### Выбор темы маршрута

- **Цель:** Пользователь хочет выбрать интересующую тему для прогулки
- **Описание:** При старте бот приветствует пользователя вопросом «Куда хотите отправиться?» и показывает кнопки с темами: «Архитектура», «Мистика», «Особняки», «Литература», «Современный Петербург». Пользователь нажимает на тему и получает маршрут.
- **Критерии приёмки:**
  - При старте бот приветствует пользователя с вопросом «Куда хотите отправиться?»
  - Список тем отображается всегда, когда пользователь может сделать выбор
  - Доступны темы: Архитектура, Мистика, Особняки, Литература, Современный Петербург
  - Каждая тема имеет понятное название и короткое описание
  - У каждой темы есть подходящий эмодзи-значок (например, 🏛 для архитектуры, 🔮 для мистики и т.д.)

### Приветствие от имени гида

- **Цель:** Пользователь чувствует, что его встречает живой гид, а не программа
- **Описание:** При команде /start бот приветствует пользователя дружелюбным сообщением от имени Михаила из «Кода Петербурга», автоматически подставляя имя пользователя из Telegram. Над приветствием отображается логотип Go Kod Bot. Текст приветствия: «Привет! Это Михаил из «Кода Петербурга». Рад, что ты заглянул! Я не просто бот, а твой гид по небанальным маршрутам, которые я сам собрал, потому что влюблён в этот город. Готов исследовать?» с дружелюбным эмодзи в конце.
- **Критерии приёмки:**
  - При команде /start отображается дружелюбное приветствие от имени Михаила из «Кода Петербурга»
  - Над приветствием отображается логотип Go Kod Bot
  - В приветствие автоматически подставляется имя пользователя из Telegram
  - Текст приветствия соответствует заданному и заканчивается дружелюбным эмодзи

### Генерация маршрута по теме

- **Цель:** Пользователь хочет получить готовый маршрут по выбранной теме
- **Описание:** После выбора темы бот отправляет маршрут по точкам. Каждая точка содержит название, короткое описание, адрес и своё уникальное фото. Пользователь может перемещаться между точками и раскрывать подробности. В конце маршрута — фраза «Хотите увидеть это с гидом? Забронируйте экскурсию на сайте spbkod.ru» с ссылкой.
- **Критерии приёмки:**
  - Маршрут содержит 3–5 точек с названием, описанием, адресом и фото
  - У каждой точки маршрута своё уникальное фото (не повторяется для разных точек одной темы)
  - Пользователь может перемещаться между точками с помощью кнопок навигации
  - Подробности точки раскрываются в том же сообщении, не создавая новых сообщений
  - После маршрута отображается фраза с призывом забронировать на spbkod.ru
  - Маршрут можно получить заново или вернуться к выбору темы

### Детали точки маршрута

- **Цель:** Пользователь хочет узнать подробнее о конкретной локации
- **Описание:** Под точкой маршрута доступна кнопка «Подробнее», которая раскрывает расширенное описание: историю места, интересный факт, статус и доступ (режим работы, как попасть) и фото. Блоки «Статус» и «Доступ» снабжены эмодзи, а ссылки на сайты музеев кликабельны. Для коротких описаний (до ~1024 символов) детали раскрываются в том же фото-сообщении, а для длинных — отправляются отдельным текстовым сообщением, поскольку подпись фото в Telegram ограничена 1024 символами. Кнопка «Свернуть описание» в длинной точке удаляет отдельное текстовое сообщение с деталями, оставляя фото точки с кратким описанием, а в короткой точке восстанавливает краткое описание прямо в том же фото-сообщении через editMessageCaption, без создания новых сообщений и без удаления.
- **Критерии приёмки:**
  - У каждой точки маршрута есть кнопка «Подробнее»
  - Расширенное описание содержит историю или интересный факт и фото
  - Короткие описания (в пределах лимита подписи) раскрываются в том же фото-сообщении
  - Длинные описания отправляются отдельным текстовым сообщением с теми же кнопками навигации, не обрываясь из-за лимита подписи фото
  - Из деталей можно вернуться к маршруту
  - В коротких точках «Свернуть описание» восстанавливает краткое описание в том же фото-сообщении
  - В длинных точках «Свернуть описание» удаляет текстовое сообщение с деталями, оставляя фото точки с кратким описанием

### Сохранение и шеринг маршрута

- **Цель:** Пользователь хочет сохранить маршрут или поделиться им
- **Описание:** На последней точке каждого маршрута кнопки расположены в 4 ряда: ряд 1 — «Назад» (слева) и «Подробнее» (справа), ряд 2 — «Хочу экскурсию», ряд 3 — «Поделиться маршрутом», ряд 4 — «Выбрать другую тему». На не-последних точках навигация прежняя: ряд 1 — «Назад»/«Следующая», ряд 2 — «Подробнее», ряд 3 — «Выбрать другую тему». При нажатии «Поделиться маршрутом» бот генерирует уникальный QR-код со ссылкой на бота вида https://t.me/GoKodBot?start=route_<название маршрута> и отправляет его пользователю как изображение. QR-код чистый и минималистичный (чёрный на белом), его можно скачать или переслать в любой мессенджер/соцсеть. После отправки QR-кода бот предлагает кнопки «В начало» и «Хочу экскурсию».
- **Критерии приёмки:**
  - На последней точке каждого маршрута кнопки идут в порядке: «Назад»/«Подробнее», «Хочу экскурсию», «Поделиться маршрутом», «Выбрать другую тему»
  - QR-код уникален для каждого маршрута и ведёт на бота по ссылке https://t.me/GoKodBot?start=route_<название>
  - QR-код отправляется как изображение (фото-вложение) и пригоден для сторис и постов
  - QR-код аккуратный и легко сканируется
  - После отправки QR-кода есть кнопки «В начало» и «Хочу экскурсию»

### Финальный экран «Хочу увидеть это с гидом»

- **Цель:** Пользователь, дошедший до конца маршрута, хочет узнать, как забронировать живую экскурсию
- **Описание:** При нажатии «Хочу экскурсию» бот показывает финальный текст «Маршрут завершён 🎉 … Хотите увидеть это с гидом? … или свяжитесь со мной напрямую @mikegorov». После слов «…напрямую @mikegorov» с новой строки добавлено: «Подписывайтесь на мой телеграм канал, там много интересного про Петербург @spbcode», где @spbcode — кликабельная ссылка на https://t.me/spbcode. Под текстом кнопки: «Поделиться маршрутом», «Назад к выбору маршрута» и «🌐 Сайт spbkod.ru». Текст финала и поведение генерации QR-кода не менялись.
- **Критерии приёмки:**
  - Финальный текст заканчивается кликабельной ссылкой на канал @spbcode (https://t.me/spbcode)
  - Под финальным текстом кнопки: «Поделиться маршрутом», «Назад к выбору маршрута» и «🌐 Сайт spbkod.ru»
  - Повторная кнопка «Хочу экскурсию» на этом экране отсутствует

### Аналитика использования (только для владельца)

- **Цель:** Владелец бота (Telegram ID 220049710) может видеть статистику использования бота. Никто другой статистику не видит.
- **Описание:** Бот накопительно хранит аналитику по всем пользователям (в Upstash Redis / Vercel KV, переживает рестарт): число запусков /start, выбранные темы, открытые точки и факт достижения последней точки маршрута, длительность сеансов, число нажатий «Поделиться маршрутом» и число переходов на сайт/канал. Сбор данных полностью фоновый, не меняет обычное поведение бота и не добавляет лишних сообщений. Команда /stats показывает отчёт только владельцу (ID 220049710), для остальных отвечает вежливым отказом.
- **Критерии приёмки:**
  - Команда /stats доступна только владельцу бота (Telegram ID 220049710), остальным — вежливый отказ
  - Отчёт содержит: общее число заходов, заходы по темам, достижение последней точки по темам, среднюю и суммарную длительность сеансов, число нажатий «Поделиться маршрутом» и число переходов на сайт/канал
  - Данные хранятся персистентно (Upstash Redis / Vercel KV) и накапливаются по всем пользователям
  - Аналитика полностью фоновая и не изменяет обычное поведение бота

### Работа в Telegram

- **Цель:** Пользователь может пользоваться ботом прямо в Telegram
- **Описание:** Бот работает как настоящий Telegram-бот: подключается к Telegram через Bot API, обрабатывает команды (/start, /help, /about) и нажатия на кнопки, отправляет маршруты и детали точек прямо в чат Telegram. Размещается на Vercel и работает 24/7. Фото маршрутов отправляются как вложения.
- **Критерии приёмки:**
  - Бот отвечает на команду /start дружелюбным приветствием от имени Михаила с логотипом и подстановкой имени пользователя
  - Бот показывает кнопки с темами маршрутов (с эмодзи-значками)
  - При выборе темы бот отправляет маршрут с точками, описаниями, адресами и уникальными фото (как вложения)
  - У каждой точки есть кнопка «Подробнее» с расширенным описанием
  - Бот работает на Vercel и доступен в Telegram

- Приветствие: «Куда хотите отправиться?»
- Конкретные темы: Архитектура, Мистика, Особняки, Литература, Современный Петербург
